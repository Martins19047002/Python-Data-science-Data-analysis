# Indiana COVID-19 Project Summary

This report creates a concise summary of the project and its main analytical contributions.

## Overview

The Indiana COVID-19 project explores how pandemic indicators changed over time in the state. It uses a local sample dataset that includes daily cases, cumulative cases, daily deaths, cumulative deaths, test positivity rate, and vaccination totals.

## What the analysis shows

- Daily case counts rose and fell across multiple periods, suggesting wave-like patterns.
- New deaths often lagged behind spikes in cases, showing the importance of interpreting delays in public health reporting.
- Testing and positivity both help explain how the epidemic changed over time.
- Vaccination totals steadily increased, which is relevant when interpreting changes in severe outcomes.

## Why the project matters

This project is useful for demonstrating how public health data can be explored, interpreted, and communicated. It integrates notebook analysis, data preparation, and dashboard storytelling in a way that is suitable for a portfolio or class project.
