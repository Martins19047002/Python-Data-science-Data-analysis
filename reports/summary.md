# Indiana COVID-19 Project Summary

This report intentionally keeps the project concise and easy to understand. It is designed to be used as a portfolio summary and as a starting point for a more advanced version.

## Summary

The Indiana COVID-19 project focuses on tracking the epidemic in Indiana through a time-series dataset, trend analysis, and hypothesis-driven interpretation. The dataset includes daily case counts, deaths, positivity rate, and vaccination totals, allowing for a structured view of how the pandemic evolved over time.

## Key findings from the sample dataset

- Daily case counts rose during major outbreak periods.
- Death counts were typically delayed relative to surges in cases.
- The positivity rate showed variability across time, highlighting the need to interpret testing data carefully.
- Vaccination totals increased over time, which is a relevant factor in the evaluation of severe outcomes.

## Data and methods

The analysis uses a CSV dataset, Python, pandas, matplotlib, seaborn, and Streamlit. A Jupyter Notebook is provided for reproducible data exploration and narrative analysis.

## Why this matters

This project demonstrates how public health data can be used to identify important patterns, form research questions, and communicate insights through dashboards and analysis notebooks.
